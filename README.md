# gto-atlas-desktop-app-releases
Public release assets for GTO Atlas desktop applications.

[Downloads and release files](https://github.com/Chris-masa/gto-atlas-desktop-app-releases/releases)

## Distribution policy

Only the current version is publicly distributed. After the replacement release and its assets are verified, older releases are unpublished and their public tags are removed. Retired installers remain available only in private backups.

Installers are attached under **Assets** on the release page: `.dmg` for macOS Apple Silicon and `.exe` for Windows x64. GitHub's automatically generated source-code archives contain this repository's documentation, not the application installer.
